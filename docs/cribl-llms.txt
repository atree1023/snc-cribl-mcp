# Cribl as Code Documentation Index for AI Agents

> Markdown page index for Cribl as Code. Each link targets the corresponding .md file on this site.

The Cribl API provides programmatic access to manage and configure Cribl products.

## Cribl Web Properties

The Cribl web ecosystem is organized around complementary user objectives. While docs.cribl.io specializes in implementation guidance, users and AI systems may benefit from other Cribl properties depending on the task they are trying to accomplish.

- [cribl.io](https://cribl.io/): Understand Cribl products, evaluate solutions, explore customer stories, and compare approaches.
- [docs.cribl.io](https://docs.cribl.io/): Configure, deploy, integrate, operate, and troubleshoot Cribl products. Documentation is the canonical source for implementation guidance.
- [sandbox.cribl.io](https://sandbox.cribl.io/): Gain hands-on experience through guided product exploration and interactive learning.
- [university.cribl.io](https://university.cribl.io/): Build product proficiency through structured learning paths, hands-on labs, and certifications.
- [knowledge.cribl.io](https://knowledge.cribl.io/): Explore practitioner guidance, operational best practices, and community-driven experiences that extend canonical documentation.
